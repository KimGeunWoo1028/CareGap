# CareGap Design System — Midnight Transit Evidence Map

> Implemented after Impeccable direction choice (challenger transit diagram) with user steers.

## Brand
- Mark: interchange circle where two routes meet (`components/brand-mark.tsx`)
- Shell: midnight enamel; work content: porcelain plates

## Color
| Token | Value | Role |
|---|---|---|
| `--navy` | `#0b1c33` | Canvas / shell |
| `--porcelain` / pure | `#f4f7fb` / `#fff` | Work surfaces |
| `--scarlet` | `#e23b2f` | Previous route |
| `--cobalt` | `#2f6fed` | Current route / primary action |
| `--amber` | `#f0a202` | Status tick / brand accent |
| `--ink` / `--text` | `#142033` / `#1c2b40` | Body on porcelain |

## Type
Pretendard Variable. Work body `--body-work: 1.125rem`. Login display heavy weight.

## Metaphor rule
Route lines/connectors appear only for previous↔current evidence relationship. No decorative network graphs or KPI charts.
