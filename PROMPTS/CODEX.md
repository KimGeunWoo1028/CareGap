# Codex 시작 프롬프트

Codex 프로젝트 루트에 이 패키지를 놓는다. Codex의 [AGENTS.md](../AGENTS.md)는 공통 프로젝트 지침이다. 아래를 붙여 넣고, 이어서 [IMPLEMENTATION_PHASES.md](IMPLEMENTATION_PHASES.md)의 단계 하나를 선택해 붙여 넣는다.

```text
이 저장소의 AGENTS.md, README.md, INDEX.md와 지금 수행할 단계가 지정한 문서들을 읽고 CareGap AI 해커톤 MVP를 구현해 주세요. 문서의 P0와 합성 데이터 경계를 지키고 현재 파일과 변경사항을 먼저 확인하세요. 코드 및 관련 테스트를 작업하되 문서에 없는 기능, 실제 개인 데이터, 서비스 자동 신청은 추가하지 마세요. 단계별 완료 조건을 확인하고 실행한 검사와 실행하지 못한 이유를 보고해 주세요. 이제 아래의 한 단계만 수행합니다.
```

완료 후 다음 단계로 이동할 때는 이전 검사 결과·차단 사항을 전달한다. 실제 코드가 생긴 뒤 검토 요청 예: “API_SPEC과 SRS 기준으로 소유권, 멱등성, 근거 검증에 집중해 바뀐 코드를 검토하고 재현 가능한 결함만 보고해 주세요.”
