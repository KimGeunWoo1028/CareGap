# Claude / Claude Code 시작 프롬프트

Claude Code에서는 프로젝트 루트의 `CLAUDE.md`가 `AGENTS.md`를 참조한다. 일반 Claude 채팅에서는 로컬 파일 접근을 가정하지 말고 아래 프롬프트와 필요한 문서를 직접 첨부한다. 이어서 [IMPLEMENTATION_PHASES.md](IMPLEMENTATION_PHASES.md)의 원하는 단계 하나를 제공한다.

```text
첨부한 AGENTS.md, INDEX.md, SRS.md 및 현재 단계의 참조 문서를 제품 계약으로 사용해 CareGap AI를 구현해 주세요. 한 대상자의 합성 기록 두 시점을 비교하고, 네 범주의 변화와 검증된 원문 근거, 기존 사업의 자격 미확인 후보를 보여 주는 담당자 보조 도구입니다. 현재 단계의 범위만 수정하고 나머지 파일과 팀원의 작업을 보존하세요. 실개인정보, 진단, 자격 확정, 자동 신청, 보이지 않는 replay 전환은 금지합니다. 테스트를 실행하고 성공·실패·실행 불가와 실제 근거를 보고해 주세요. 아래 한 단계부터 시작합니다.
```

파일 읽기/명령 실행 기능이 없는 채팅 환경이라면 코드를 파일별로 제안하고 사용자가 별도로 적용·검증하도록 안내한다. 없는 파일을 이미 수정한 것처럼 말하지 않는다.
